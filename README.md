# Motio

Motion design simple pour tutoriels et trailers.

## Démarrer

```bash
npm install
npm run dev        # application Electron avec rechargement à chaud
npm run dev:web    # interface seule dans le navigateur : http://localhost:5180
npm test           # tests du moteur et du store
npm run typecheck
npm run build      # build de production dans out/
npm run dist       # application macOS : dist/Motio-0.1.0-arm64.dmg et dist/mac-arm64/Motio.app
```
