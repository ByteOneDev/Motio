# Story 6.2 — Zoom caméra sur une capture

**Statut : Review** · Epic 6 — Outils pour tutoriels

## Critères d'acceptation
- [x] Sur une image ou une vidéo : « Zoom ici » ajoute un zoom à la tête de lecture
- [x] Choix du point à montrer en cliquant sur un aperçu de la source ; le cadre visible est dessiné
- [x] Réglages : grossissement, début, durée, durée de l'aller-retour (lissé)
- [x] Les zooms apparaissent en bleu sur la barre du média dans la timeline ; ils suivent le calque quand on le déplace
- [x] Le zoom ne sort jamais de l'image
