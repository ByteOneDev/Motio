# Story 6.3 — Sous-titres manuels

**Statut : Review** · Epic 6 — Outils pour tutoriels

Choix produit : pas de transcription automatique (elle imposerait un modèle d'IA lourd). L'auteur écrit ses
sous-titres — à partir de son script, c'est rapide.

## Critères d'acceptation
- [x] Tuile « Sous-titres » (Éléments › Tutoriel) : une piste de sous-titres
- [x] Coller le script : découpe en phrases (coupées si trop longues), chacune le temps de la lire
- [x] Mode calage : lecture, puis Entrée à chaque nouvelle phrase ; Échap pour arrêter ; une seule étape d'historique
- [x] Liste éditable : texte, début, fin, suppression, ajout à la tête de lecture
- [x] Import et export .srt (YouTube, logiciels de montage)
- [x] Style : police, taille, graisse, couleurs, fond ou contour, hauteur, largeur ; animation aucune / fondu / pop / karaoké mot par mot
- [x] Les phrases apparaissent dans la piste de la timeline
