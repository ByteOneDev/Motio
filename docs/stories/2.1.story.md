# Story 2.1 — Timeline

**Statut : Review** · Epic 2 — Animation

**En tant que** créateur, **je veux** voir et régler dans le temps l'apparition de chaque élément.

## Critères d'acceptation
- [x] Une ligne par calque : en-tête (nom, visibilité, verrou, réordonner) + piste
- [x] Barre de présence `[start, end[` : glisser pour déplacer (les keyframes suivent), bords pour ajuster début / fin
- [x] Zones hachurées d'entrée et de sortie, avec une poignée pour régler leur durée ; mise en avant en ambre
- [x] Losanges des keyframes (toutes propriétés confondues) : clic = sélection + tête de lecture, glisser = déplacer, ⌫ = supprimer
- [x] Règle graduée, clic/glisser sur la règle ou une zone vide = déplacer la tête de lecture
- [x] Aimantation (6 px) aux bords des autres calques, à 0, à la fin et à la tête de lecture ; Maj pour désactiver
- [x] Temps toujours calés sur les images (1/fps)
- [x] Zoom de la timeline (curseur, 1× à 12×), défilement automatique pendant la lecture
