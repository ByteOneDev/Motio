# Story 2.3 — Animations prédéfinies (entrée, mise en avant, sortie)

**Statut : Review** · Epic 2 — Animation

**En tant que** créateur, **je veux** animer un élément en un clic, sans keyframes.

## Critères d'acceptation
- [x] Trois emplacements par calque : Entrée, Accent (mise en avant), Sortie
- [x] Entrée / sortie : Fondu, Glissement, Pop, Zoom, Flou, Volet (+ Machine à écrire pour le texte, Tracé pour les formes)
- [x] Mise en avant : Pulsation, Secousse, Balancement, Rebond, Clignotement — début, durée, intensité, répétition jusqu'à la sortie
- [x] Réglages minimaux : durée, courbe (7 courbes nommées en français), direction et distance quand c'est pertinent
- [x] Valeurs par défaut qui « rendent bien » sans retouche (ex. Pop avec dépassement)
- [x] Choisir un preset lance un aperçu de la portion concernée ; bouton « ▶ Aperçu »
- [x] Entrée et sortie réduites proportionnellement si le calque est trop court
- [x] La scène d'exemple est animée (pop, volet, glissement, fondus de sortie)
