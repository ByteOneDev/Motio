# Story 4.4 — Application macOS

**Statut : Review** · Epic 4 — Export & fichiers

## Critères d'acceptation
- [x] `npm run dist` produit `dist/Motio-0.1.0-arm64.dmg` et `dist/mac-arm64/Motio.app` (Apple Silicon)
- [x] Nom « Motio », icône Motio, menu en français, association des fichiers `.motio`
- [x] Aucune dépendance copiée dans l'application (tout est compilé par Vite) ; le binaire Electron local est réutilisé
- [x] Démarrage vérifié sans erreur, protocole des médias et sauvegarde automatique testés dans l'app empaquetée

## Limites
- Application non signée : parfaite pour un usage personnel. Pour la distribuer, il faudra un compte Apple Developer
  (signature + notarisation), sinon macOS bloquera son ouverture sur d'autres Mac.
