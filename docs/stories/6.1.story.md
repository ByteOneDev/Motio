# Story 6.1 — Enregistrer l'écran et la voix off

**Statut : Review** · Epic 6 — Outils pour tutoriels

## Critères d'acceptation
- [x] Bouton « Enregistrer » (barre du haut) : mode Écran ou Voix off
- [x] Écran : choix de l'écran ou de la fenêtre sur miniatures, micro au choix (ou sans son)
- [x] Compte à rebours de 3 s, option « réduire Motio », arrêt par le bouton ou ⇧⌘2 depuis n'importe quelle application
- [x] Voix off : la séquence défile pendant qu'on parle ; la voix est posée à l'endroit de départ
- [x] Le fichier est rendu navigable (durée, index) puis enregistré dans Vidéos › Motio et ajouté à la timeline
- [x] Message clair si macOS n'a pas encore autorisé l'enregistrement de l'écran, avec un bouton vers les Réglages

## Notes
- Vérifié : la chaîne MediaRecorder → remultiplexage → lecture navigable (fichier brut : durée « infinie »).
- La capture réelle d'un écran demande l'autorisation macOS au premier essai : à tester par l'utilisateur.
