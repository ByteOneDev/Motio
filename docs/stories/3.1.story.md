# Story 3.1 — Import d'images et de vidéos

**Statut : Review** · Epic 3 — Médias & modèles

**En tant que** créateur, **je veux** glisser mes captures d'écran et mes vidéos dans la séquence.

## Critères d'acceptation
- [x] Onglet « Médias » : bouton d'import (PNG, JPEG, GIF, WebP, SVG, MP4, WebM, MOV) et zone de dépôt
- [x] Glisser des fichiers du Finder sur le canevas : import + calque placé à l'endroit du dépôt, à la tête de lecture
- [x] Médias importés listés avec miniature ; clic ou glisser vers le canevas pour les réutiliser ; suppression (avec leurs calques, annulable)
- [x] Calque média : boîte aux proportions du fichier ; coins = redimensionnement proportionnel (Maj pour libérer)
- [x] Réglages : Remplir / Entière / Étirer, arrondi des coins, ombre portée, bordure (animable en couleur)
- [x] Vidéo : calée sur la tête de lecture (lecture native pendant la lecture, recherche image par image à l'arrêt), point de départ dans la source ; durée du calque = durée de la vidéo
- [x] Un fichier lâché hors d'une zone prévue ne remplace pas l'application

## Notes de dev
- Images intégrées au projet (URL data) ; vidéos référencées par URL blob + chemin disque (`webUtils.getPathForFile`) pour la sauvegarde (Epic 4)
- `ui/media.ts` : décodage, synchronisation vidéo, import ; `renderFrame` reçoit un `MediaResolver`
- Son des vidéos coupé pour l'instant (export audio : Epic 4)
