# Story 2.4 — Keyframes manuelles et courbes

**Statut : Review** · Epic 2 — Animation

## Critères d'acceptation
- [x] Propriétés animables : position X / Y, échelle, rotation, opacité, couleur (texte, remplissage ou trait)
- [x] Losange ◇ à côté de chaque propriété : démarre l'animation / ajoute ou retire une keyframe ; Alt+clic supprime l'animation
- [x] État visible : vide (statique), contour (animée), plein (keyframe à l'instant courant)
- [x] Auto-key : une fois une propriété animée, toute modification (canevas, poignées, clavier, champs) crée/met à jour une keyframe à l'instant courant
- [x] Panneau « Image clé » quand un losange est sélectionné : courbe vers la keyframe suivante, suppression
- [x] Le panneau de propriétés et le canevas affichent les valeurs animées à l'instant courant
- [x] Aucune entrée d'historique parasite (testé)
