# Story 4.2 — Export MP4

**Statut : Review** · Epic 4 — Export & fichiers

## Critères d'acceptation
- [x] Bouton « Exporter » (⌘E) : fenêtre avec format, résolution (½, 1×, 2×), qualité (Standard, Haute, Maximale), plage
- [x] MP4 H.264, encodage matériel via WebCodecs (Mediabunny), dimensions paires, images clés toutes les 2 s
- [x] Rendu identique à l'aperçu (même `renderFrame`), polices chargées avant la première image, vidéos calées image par image
- [x] Progression (image n / total, temps restant), annulation, « Afficher dans le Finder »
- [x] Performance : 30 images 1080p en ≈ 0,3 s (objectif PRD : 10 s en < 15 s)
- [x] Image PNG : export de l'image courante (miniature)
